# Data rights and display policy

| Status | Meaning in this project | Current value |
|---|---|---|
| `SYNTHETIC_DEMO` | Every price is generated by the canonical generator; no market finding is asserted | **active (default dataset)** |
| `REAL_UNVALIDATED` | Real source data exists, but validation/adjustment requirements are incomplete | no real data present |
| `REAL_RESEARCH_VALIDATED` | Necessary source and numerical checks passed for the stated research scope | not achieved |
| `PUBLIC_DISPLAY_PERMITTED` | Separately documented permission for a specific display route | **false** (`config/display_policy.yaml`) |

Rules implemented:

1. **Technical access is not permission.** `public_display_permitted` is read only from `config/display_policy.yaml`; no provider code can set
   it. A successful NSE request (tested with a mocked transport) leaves it false.
2. **NSE MCP terms.** According to the build specification, NSE's MCP documentation (https://www.nseindia.com/nse-mcp) limits the service to
   informational use and excludes commercial deployment, and its terms do not establish redistribution or training rights. This build could
   **not** re-read that page or the NSE data policy (https://www.nseindia.com/static/market-data/nse-data-policy): both hosts were denied by the
   environment's egress policy on 2026-10-01. Re-verify these primary sources before any use of NSE data.
3. **Local research only.** NSE-derived data may be used for local/private research on this machine. Public or demo display must use synthetic
   data until permissions are established. An older or anonymized real chart is not automatically redistributable.
4. **Educational-history age gate.** Route `public_educational` (disabled by default) truncates the dataset server-side to observations dated
   ≤ reference date − 45 calendar days before any endpoint sees it. This covers scanner, pair detail, playback, reveals, backtests, run bundles,
   PNG cards and caches (gated data has its own content hash and cache namespace). Real data on that route is refused while permission is
   absent. The 45-day value is a conservative product buffer, **not legal permission**. Per the build specification, the SEBI education
   price-data circular of 8 May 2026 (https://www.sebi.gov.in/sebi_data/attachdocs/may-2026/1778242522289.pdf) uses a 30-day lag. That
   document could not be fetched here (egress denied) and must be verified before any launch.
5. **No credentials, no scraping.** No broker connection, no paid data, no unofficial scraping, no bypassing of access controls.
6. **Retention.** Imported user datasets live under `data/imports/` (git-ignored) with a manifest declaring permitted usage and retention. Raw
   market-data dumps must not be committed.
